Implemented in work/client.py:

- **`list_all()`** — cursor pagination until `next_cursor` is null, preserving server order; optional `page_size` passthrough.
- **Retry core (`_send_until_stable`)** — retries 500/429 up to `max_retries` consecutive attempts per logical step; sleeps `float(Retry-After)` when present else `backoff_base * 2**attempt`, always via the injected `sleeper`; success resets the counter; exhaustion raises `ApiError(..., attempts=max_retries)`.
- **`create_order()`** — POST with `Authorization: Bearer <token>` + JSON body; on 401 calls `refresh()` once and retries exactly once more; second 401 → `AuthError`.
- **`refresh()`** — POST `/auth/refresh`; non-200 (403) → `AuthError`, otherwise stores returned token.
